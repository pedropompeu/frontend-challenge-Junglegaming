# Rastreabilidade dos requisitos

Cada requisito do [enunciado](https://github.com/junglegaming/frontend-challenge) → onde está implementado → qual teste cobre. Os caminhos de código são relativos a `src/`. Os testes E2E ficam em `tests/e2e/` e os unitários em `tests/unit/`. Contratos, decisões e limitações estão detalhados no [`ARCHITECTURE.md`](ARCHITECTURE.md).

Legenda: ✅ atendido · ◐ atendido em parte (motivo na linha) · ⚠ abaixo da meta (justificado).

## 2. Stack obrigatória

| Tecnologia         | Onde participa                                                                                                                                                        |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| React + TypeScript | Toda a app, `strict` (`tsconfig.app.json`); `pnpm typecheck`                                                                                                          |
| TanStack Router    | Rotas por arquivo em `routes/`, `validateSearch` com zod no catálogo e no detalhe, guard `_auth.tsx`, loaders com `ensureQueryData`, `head` por rota, 404 no `__root` |
| TanStack Query     | Todo o estado remoto: `features/*/queries.ts`, `app/query-client.ts` (retries, `staleTime`), mutations com rollback, `setQueryData` dos eventos                       |
| Axios              | Único cliente HTTP: `shared/lib/http.ts` (interceptors de token e `X-Guest-Id`, normalização de erros, validação por schema)                                          |
| REST               | 27 rotas em `/api` (tabela no ARCHITECTURE §3)                                                                                                                        |
| Socket.IO          | `socket.io-client` em `shared/lib/socket.ts` e `features/realtime/realtime-provider.tsx`; servidor simulado em `mocks/socket/`                                        |
| Tailwind CSS       | v4, tokens do Figma em `index.css` (`@theme`)                                                                                                                         |
| shadcn/ui          | `shared/ui/` (Radix) retematizado: Dialog, Sheet, Select, Tabs, RadioGroup, Slider, Checkbox, Dropdown, Tooltip, Carousel, Form                                       |
| MSW                | `mocks/handlers/` (REST) e `@mswjs/socket.io-binding` (eventos), ativados por `VITE_ENABLE_MOCKS`                                                                     |
| Playwright         | 86 testes × 2 projetos em `tests/e2e/`, regressão visual com baselines versionadas                                                                                    |
| Lighthouse         | `lighthouserc.mobile.cjs`, `lighthouserc.desktop.cjs`, `pnpm lighthouse`, `lighthouse/`                                                                               |
